# LAN 1v1 Tetris Duels — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Friends on the same LAN open `http://<host-ip>:8080` in a browser and play 1v1 Tetris duels with garbage attacks, served by a small Go server on the host's Mac.

**Architecture:**
- The existing C++20 SDL3 + ImGui game is compiled to WebAssembly with Emscripten.
- Each browser simulates only its own board. It sends attacks (`ATK n`) and 10 Hz board snapshots (`SNAP …`) through a Go WebSocket relay that also manages 4-letter room codes and match seeds.
- The opponent's board is display-only.
- The native desktop build stays single-player and unchanged.

**Tech Stack:** C++20, CMake ≥ 3.25, SDL3 (Homebrew on desktop, Emscripten `-sUSE_SDL=3` port on web), Dear ImGui 1.92.9b (SDL_GPU backend on desktop, OpenGL3/WebGL backend on web), doctest 2.4.12, Emscripten (`brew install emscripten`), Go 1.27 + `github.com/coder/websocket`.

**Spec:** `docs/superpowers/specs/2026-10-13-lan-duel-design.md` (written in Task 0 from the approved brainstorming design)

## Global Constraints

- C++20; every C++ target builds warning-free with `-Wall -Wextra -Wpedantic`. Desktop Debug builds keep ASan/UBSan.
- Desktop (`./build/tetris`) solo gameplay and menus stay exactly as today. Duel UI appears only when `duelsSupported()` is true, which happens only in the browser build.
- Web build: **no pthreads or SharedArrayBuffer**, because plain-HTTP LAN pages are not a secure context. Output is `build-web/index.html`, `index.js` and `index.wasm`.
- Attack table: clearing 1/2/3/4 lines sends **0/1/2/4** lines. Attack cancels pending garbage first. Pending garbage rises only on a lock that clears no lines, all at once, with one gap column per batch.
- Countdown is 3000 ms. Snapshots go out every 100 ms, and only when changed. Room codes are 4 letters from `ABCDEFGHJKLMNPQRSTUVWXYZ`. Server read limit is 4096 bytes. Start level is 1–15.
- Server: Go module in `server/`, one dependency `github.com/coder/websocket`. Default `-addr 0.0.0.0:8080 -dir ../build-web`. Run with `go -C server run .`.
- Conventional commit messages scoped like the existing history (`feat(core): …`, `feat(app): …`, `feat(server): …`).
- Work on branch `feat/lan-duel`, not `main`.

## Review Focus

1. **Opponent disconnects mid-match.** Expect "YOU WIN / Opponent left the match", Rematch hidden, and Leave returns to the menu. Pinned in Task 4 (`duel: opponent leaving mid-match wins and blocks rematch`) and Task 7 (`TestDisconnectTellsOpponent`).
2. **Wrong or full room code.** Expect an error on the start screen and the ability to try again, not a hang. Pinned in Task 4 (`duel: a refused join returns to idle with the reason`) and Task 7 (`TestJoinErrors`).
3. **Host server stopped or unreachable.** Expect a return to the start screen with "Connection lost". Pinned in Task 4 (`duel: losing the connection returns to idle`). Wired in Task 8 (`pumpNetwork`).
4. **Garbage larger than the board, or junk from the wire.** Expect a top-out, never a crash, and malformed messages ignored. Pinned in Task 2 (`garbage that pushes blocks off the top ends the game`) and Task 3 (`malformed messages are rejected`).
5. **Messages arriving at the wrong time** (late `SNAP` after `LEFT`, `START` after leaving, relay before joining). These must not kick players to the menu or restart a match. Pinned in Task 4 (`duel: messages are ignored once idle`) and Task 7 (`TestMessagesOutsideARoomAreDropped`).

```cpp
bool Board::pushGarbage(int rows, int gapX) {
    assert(rows >= 0 && gapX >= 0 && gapX < kBoardWidth);
    rows = std::min(rows, kBoardHeight);
    for (int y = kBoardHeight - rows; y < kBoardHeight; ++y)
        for (int x = 0; x < kBoardWidth; ++x)
            if (cells_[index(x, y)]) return false;
    for (int y = kBoardHeight - 1; y >= rows; --y)
        for (int x = 0; x < kBoardWidth; ++x) cells_[index(x, y)] = cells_[index(x, y - rows)];
    for (int y = 0; y < rows; ++y)
        for (int x = 0; x < kBoardWidth; ++x) cells_[index(x, y)] = x == gapX ? Cell{} : Cell{PieceType::Garbage};
    return true;
}
```

```cpp
namespace {
constexpr std::uint32_t kGarbageSeedSalt = 0x9E3779B9u;  // keeps gap columns independent of the bag
}  // namespace

int attackFor(int lines) {
    static constexpr std::array<int, 5> kAttack{0, 0, 1, 2, 4};
    assert(lines >= 0 && lines <= 4);
    return kAttack[lines];
}

Game::Game(std::uint32_t seed, int startLevel, Board board, GameOptions options)
    : board_(std::move(board)),
      bag_(seed),
      options_(options),
      garbageRng_(seed ^ kGarbageSeedSalt),
      startLevel_(startLevel),
      level_(startLevel) {
    assert(startLevel >= 1);
    spawn(bag_.next());
}

void Game::receiveGarbage(int lines) {
    assert(lines >= 0);
    pendingGarbage_ += lines;
}

int Game::takeOutgoingAttack() { return std::exchange(outgoingAttack_, 0); }

bool Game::applyGarbage() {
    if (pendingGarbage_ == 0) return true;
    const int gapX = static_cast<int>(garbageRng_() % kBoardWidth);
    return board_.pushGarbage(std::exchange(pendingGarbage_, 0), gapX);
}
```

```cpp
#pragma once

#include <array>
#include <cstdint>
#include <optional>
#include <string>
#include <string_view>
#include <variant>

#include "core/game.hpp"

namespace tetris {

inline constexpr int kSnapshotCells = kBoardWidth * kVisibleHeight;
inline constexpr int kRoomCodeLength = 4;

// What the opponent sees of a board: the visible field with the falling piece merged in.
struct Snapshot {
    int score = 0;
    int lines = 0;
    int pending = 0;                           // garbage waiting to rise
    std::array<Cell, kSnapshotCells> cells{};  // index y * kBoardWidth + x; y = 0 is the bottom row
    friend bool operator==(const Snapshot&, const Snapshot&) = default;
};

Snapshot snapshotOf(const Game& game);

// Messages between a browser and the duel server. Attack, Snapshot and Dead are relayed to the opponent.
struct CreateRoom {
    int startLevel = 1;
    friend bool operator==(const CreateRoom&, const CreateRoom&) = default;
};
struct JoinRoom {
    std::string code;
    friend bool operator==(const JoinRoom&, const JoinRoom&) = default;
};
struct RoomCreated {
    std::string code;
    friend bool operator==(const RoomCreated&, const RoomCreated&) = default;
};
struct StartMatch {
    std::uint32_t seed = 0;
    int startLevel = 1;
    friend bool operator==(const StartMatch&, const StartMatch&) = default;
};
struct Attack {
    int lines = 0;
    friend bool operator==(const Attack&, const Attack&) = default;
};
struct Dead {
    friend bool operator==(const Dead&, const Dead&) = default;
};
struct Rematch {
    friend bool operator==(const Rematch&, const Rematch&) = default;
};
struct OpponentLeft {
    friend bool operator==(const OpponentLeft&, const OpponentLeft&) = default;
};
struct ServerError {
    std::string reason;
    friend bool operator==(const ServerError&, const ServerError&) = default;
};

using Message = std::variant<CreateRoom, JoinRoom, RoomCreated, StartMatch, Attack, Snapshot, Dead, Rematch,
                             OpponentLeft, ServerError>;

std::string encode(const Message& message);
// nullopt for anything malformed or unknown.
std::optional<Message> decode(std::string_view text);

}  // namespace tetris
```

```cpp
std::vector<std::string_view> split(std::string_view text) {
    std::vector<std::string_view> parts;
    std::size_t start = 0;
    while (start <= text.size()) {

    T value{};
    const auto [end, ec] = std::from_chars(text.data(), text.data() + text.size(), value);
    if (ec != std::errc{} || end != text.data() + text.size() || value < lo || value > hi) return std::nullopt;
    return value;
}

bool isRoomCode(std::string_view text) {
    return static_cast<int>(text.size()) == kRoomCodeLength &&
           std::all_of(text.begin(), text.end(), [](char c) { return c >= 'A' && c <= 'Z'; });
}

char cellChar(Cell cell) { return cell ? kCellChars[static_cast<int>(*cell)] : kEmptyCell; }

bool parseCell(char c, Cell& out) {
    if (c == kEmptyCell) {
        out = std::nullopt;
        return true;
    }
    const std::size_t i = kCellChars.find(c);
    if (i == std::string_view::npos) return false;
    out = static_cast<PieceType>(i);
    return true;
}

std::optional<Message> decodeSnapshot(const std::vector<std::string_view>& parts) {
    const auto score = parseNumber(parts[1], 0, kMaxInt);
    const auto lines = parseNumber(parts[2], 0, kMaxInt);
    const auto pending = parseNumber(parts[3], 0, kMaxInt);
    const std::string_view cells = parts[4];
    if (!score || !lines || !pending || static_cast<int>(cells.size()) != kSnapshotCells) return std::nullopt;
    Snapshot snapshot{*score, *lines, *pending, {}};
    for (int i = 0; i < kSnapshotCells; ++i)
        if (!parseCell(cells[i], snapshot.cells[i])) return std::nullopt;
    return snapshot;
}

}  // namespace

Snapshot snapshotOf(const Game& game) {
    Snapshot snapshot{game.score(), game.lines(), game.pendingGarbage(), {}};
    for (int y = 0; y < kVisibleHeight; ++y)
        for (int x = 0; x < kBoardWidth; ++x) snapshot.cells[y * kBoardWidth + x] = game.board().at(x, y);
    if (game.state() == GameState::Playing)
        for (Point c : game.active().cells())
            if (c.y < kVisibleHeight) snapshot.cells[c.y * kBoardWidth + c.x] = game.active().type;
    return snapshot;
}

std::string encode(const Message& message) {
    return std::visit(
        [](const auto& m) -> std::string {
            using T = std::decay_t<decltype(m)>;
            if constexpr (std::is_same_v<T, CreateRoom>) {
                return "CREATE " + std::to_string(m.startLevel);
            } else if constexpr (std::is_same_v<T, JoinRoom>) {
                return "JOIN " + m.code;
            } else if constexpr (std::is_same_v<T, RoomCreated>) {
                return "ROOM " + m.code;
            } else if constexpr (std::is_same_v<T, StartMatch>) {
                return "START " + std::to_string(m.seed) + " " + std::to_string(m.startLevel);
            } else if constexpr (std::is_same_v<T, Attack>) {
                return "ATK " + std::to_string(m.lines);
            } else if constexpr (std::is_same_v<T, Snapshot>) {
                std::string text = "SNAP " + std::to_string(m.score) + " " + std::to_string(m.lines) + " " +
                                   std::to_string(m.pending) + " ";
                for (Cell cell : m.cells) text += cellChar(cell);
                return text;
            } else if constexpr (std::is_same_v<T, Dead>) {
                return "DEAD";
            } else if constexpr (std::is_same_v<T, Rematch>) {
                return "REMATCH";
            } else if constexpr (std::is_same_v<T, OpponentLeft>) {
                return "LEFT";
            } else {
                static_assert(std::is_same_v<T, ServerError>);
                return "ERR " + m.reason;
            }
        },
        message);
}

std::optional<Message> decode(std::string_view text) {
    if (text.starts_with("ERR ") && text.size() > 4) return ServerError{std::string(text.substr(4))};
    const std::vector<std::string_view> parts = split(text);
    const std::string_view verb = parts[0];
    const std::size_t args = parts.size() - 1;
    if (verb == "CREATE" && args == 1) {
        if (const auto level = parseNumber(parts[1], kMinStartLevel, kMaxStartLevel)) return CreateRoom{*level};
    } else if (verb == "JOIN" && args == 1) {
        if (isRoomCode(parts[1])) return JoinRoom{std::string(parts[1])};
    } else if (verb == "ROOM" && args == 1) {
        if (isRoomCode(parts[1])) return RoomCreated{std::string(parts[1])};
    } else if (verb == "START" && args == 2) {
        const auto seed = parseNumber<std::uint32_t>(parts[1], 0, std::numeric_limits<std::uint32_t>::max());
        const auto level = parseNumber(parts[2], kMinStartLevel, kMaxStartLevel);
        if (seed && level) return StartMatch{*seed, *level};
    } else if (verb == "ATK" && args == 1) {
        if (const auto lines = parseNumber(parts[1], 1, kBoardHeight)) return Attack{*lines};
    } else if (verb == "SNAP" && args == 4) {
        return decodeSnapshot(parts);
    } else if (args == 0) {
        if (verb == "DEAD") return Dead{};
        if (verb == "REMATCH") return Rematch{};
        if (verb == "LEFT") return OpponentLeft{};
    }
    return std::nullopt;
}

}  // namespace tetris
```

```cpp
#pragma once

#include <functional>
#include <optional>
#include <string>
#include <string_view>
#include <utility>

#include "core/game.hpp"
#include "net/protocol.hpp"

namespace tetris {

inline constexpr int kCountdownMs = 3000;
inline constexpr int kSnapshotIntervalMs = 100;

enum class DuelPhase { Idle, Waiting, Countdown, Playing, Result };
enum class DuelOutcome { None, Won, Lost, OpponentLeft };

// The local game for a match: same seed (so the same pieces) as the opponent, and no pausing.

// reports attacks, snapshots and top-out through `send`. Knows nothing about sockets or SDL.
class DuelSession {
public:
    using Send = std::function<void(const std::string&)>;
    using MakeGame = std::function<Game(const StartMatch&)>;

        : send_(std::move(send)), makeGame_(std::move(makeGame)) {}

    void onMessage(std::string_view text);
    void onDisconnected();

    void update(int ms);

    DuelPhase phase() const { return phase_; }
    DuelOutcome outcome() const { return outcome_; }
    const std::string& roomCode() const { return roomCode_; }  // set once the server confirms a created room
    const std::string& error() const { return error_; }        // why the session last went back to Idle
    const Snapshot& opponent() const { return opponent_; }
    int countdownMs() const { return countdownMs_; }
    bool rematchRequested() const { return rematchRequested_; }
    bool opponentGone() const { return opponentGone_; }
    Game* game() { return game_ ? &*game_ : nullptr; }
    const Game* game() const { return game_ ? &*game_ : nullptr; }

private:
    void send(const Message& message) { send_(encode(message)); }
    void startMatch(const StartMatch& start);
    void finish(DuelOutcome outcome);
    void reset();

    Send send_;
    MakeGame makeGame_;
```

```cpp
#include "app/duel.hpp"

#include <variant>

namespace tetris {

Game makeDuelGame(const StartMatch& start) {
    return Game(start.seed, start.startLevel, Board{}, GameOptions{.allowPause = false});
}

void DuelSession::createRoom(int startLevel) {
    reset();
    phase_ = DuelPhase::Waiting;
    send(CreateRoom{clampStartLevel(startLevel)});
}

void DuelSession::joinRoom(const std::string& code) {
    reset();
    phase_ = DuelPhase::Waiting;
    send(JoinRoom{code});
}

void DuelSession::requestRematch() {
    if (phase_ != DuelPhase::Result || opponentGone_ || rematchRequested_) return;
    rematchRequested_ = true;
    send(Rematch{});
}

void DuelSession::leave() { reset(); }

void DuelSession::onDisconnected() {
    if (phase_ == DuelPhase::Idle) return;
    reset();
    error_ = "Connection lost";
}

void DuelSession::onMessage(std::string_view text) {
    const std::optional<Message> message = decode(text);
    if (!message || phase_ == DuelPhase::Idle) return;
    if (const auto* room = std::get_if<RoomCreated>(&*message)) {
        roomCode_ = room->code;
    } else if (const auto* start = std::get_if<StartMatch>(&*message)) {
        startMatch(*start);
    } else if (const auto* error = std::get_if<ServerError>(&*message)) {
        reset();
        error_ = error->reason;
    } else if (const auto* attack = std::get_if<Attack>(&*message)) {
        if (phase_ == DuelPhase::Playing) game_->receiveGarbage(attack->lines);
    } else if (const auto* snapshot = std::get_if<Snapshot>(&*message)) {
        opponent_ = *snapshot;
    } else if (std::holds_alternative<Dead>(*message)) {
        if (phase_ == DuelPhase::Playing) finish(DuelOutcome::Won);
    } else if (std::holds_alternative<OpponentLeft>(*message)) {
        opponentGone_ = true;
        if (phase_ != DuelPhase::Result) finish(DuelOutcome::OpponentLeft);
    }
}

void DuelSession::update(int ms) {
    if (phase_ == DuelPhase::Countdown) {
        countdownMs_ -= ms;
        if (countdownMs_ <= 0) {
            countdownMs_ = 0;
            phase_ = DuelPhase::Playing;
        }
        return;
    }
    if (phase_ != DuelPhase::Playing) return;
    if (const int lines = game_->takeOutgoingAttack(); lines > 0) send(Attack{lines});
    const bool over = game_->state() == GameState::GameOver;
    sinceSnapshotMs_ += ms;
    if (sinceSnapshotMs_ >= kSnapshotIntervalMs || over) {
        sinceSnapshotMs_ = 0;
        const Snapshot snapshot = snapshotOf(*game_);
        if (snapshot != lastSent_) {
            send(snapshot);
            lastSent_ = snapshot;
        }
    }
    if (over) {
        send(Dead{});
        finish(DuelOutcome::Lost);
    }
}

void DuelSession::startMatch(const StartMatch& start) {
    game_.emplace(makeGame_(start));
    phase_ = DuelPhase::Countdown;
    outcome_ = DuelOutcome::None;
    countdownMs_ = kCountdownMs;
    sinceSnapshotMs_ = 0;
    opponent_ = Snapshot{};
    lastSent_.reset();
    rematchRequested_ = false;
}

void DuelSession::finish(DuelOutcome outcome) {
    phase_ = DuelPhase::Result;
    outcome_ = outcome;
}

void DuelSession::reset() {
    phase_ = DuelPhase::Idle;
    outcome_ = DuelOutcome::None;
    game_.reset();
    opponent_ = Snapshot{};
    lastSent_.reset();
    roomCode_.clear();
    error_.clear();
    countdownMs_ = 0;
    sinceSnapshotMs_ = 0;
    rematchRequested_ = false;
    opponentGone_ = false;
}

}  // namespace tetris
```

```cpp
// src/app/app.cpp
#include "app/app.hpp"

#include <cstdint>

#include "app/keymap.hpp"

namespace tetris {
namespace {

void applyCommand(App& app, UiCommand command) {
    switch (command) {
    case UiCommand::None:
        break;
    case UiCommand::Play:
    case UiCommand::Restart:
        app.newGame();
        break;
    case UiCommand::Resume:
        if (app.game) app.game->resume();
        break;
    case UiCommand::QuitToMenu:
        app.game.reset();
        app.screen = Screen::Start;
        break;
    case UiCommand::QuitApp:
        app.quit = true;
        break;
    }
}

void handleKey(App& app, SDL_Window* window, const SDL_KeyboardEvent& key) {
    if (key.down && isFullscreenChord(key)) {
        const bool fullscreen = (SDL_GetWindowFlags(window) & SDL_WINDOW_FULLSCREEN) != 0;
        SDL_SetWindowFullscreen(window, !fullscreen);
        return;
    }
    if (key.repeat || app.screen != Screen::Playing) return;  // DAS/ARR replaces OS key repeat
    const std::optional<Key> mapped = keyForScancode(key.scancode);
    if (!mapped) return;
    if (key.down)
        app.input.press(*mapped, app.pending);
    else
        app.input.release(*mapped);
}

}  // namespace

void App::newGame() {
    startLevel = clampStartLevel(startLevel);
    game.emplace(static_cast<std::uint32_t>(SDL_GetTicksNS()), startLevel);
    input.releaseAll();
    pending.clear();
    screen = Screen::Playing;
}

void handleEvent(App& app, SDL_Window* window, const SDL_Event& event) {
    switch (event.type) {
    case SDL_EVENT_QUIT:
        app.quit = true;
        break;
    case SDL_EVENT_WINDOW_FOCUS_LOST:
        if (app.game) app.game->pause();
        app.input.releaseAll();  // key-up events are lost while unfocused
        break;
    case SDL_EVENT_KEY_DOWN:
    case SDL_EVENT_KEY_UP:
        handleKey(app, window, event.key);
        break;
    default:
        break;
    }
}

void step(App& app, int ms) {
    if (!app.game) return;
    Game& game = *app.game;
    auto flush = [&] {
        for (Action action : app.pending) game.apply(action);
        app.pending.clear();
    };
    flush();
    for (int i = 0; i < ms; ++i) {
        app.input.tick(app.pending);
        flush();
        game.setSoftDrop(app.input.softDrop());
        game.tick(1);
    }
}

void drawFrame(App& app, const Fonts& fonts) {
    UiCommand command = UiCommand::None;
    if (app.screen == Screen::Start) {
        command = drawStartScreen(fonts, app.startLevel);
    } else {
        drawGame(*app.game, fonts);
        command = drawOverlay(*app.game, fonts);
    }
    applyCommand(app, command);
}

}  // namespace tetris
```

```cpp
SDL_AppResult SDL_AppInit(void** appstate, int, char**) {
    if (!SDL_Init(SDL_INIT_VIDEO)) {
        std::fprintf(stderr, "SDL_Init failed: %s\n", SDL_GetError());
        return SDL_APP_FAILURE;
    }
    auto* host = new Host;
    *appstate = host;
    const float scale = SDL_GetDisplayContentScale(SDL_GetPrimaryDisplay());
    host->window = SDL_CreateWindow("Tetris", static_cast<int>(800 * scale), static_cast<int>(900 * scale),
                                    SDL_WINDOW_RESIZABLE | SDL_WINDOW_HIGH_PIXEL_DENSITY | SDL_WINDOW_HIDDEN |
                                        gfxPrepareWindow());
    if (host->window == nullptr) {
        std::fprintf(stderr, "SDL_CreateWindow failed: %s\n", SDL_GetError());
        return SDL_APP_FAILURE;
    }
    SDL_SetWindowMinimumSize(host->window, 640, 720);
    SDL_SetWindowPosition(host->window, SDL_WINDOWPOS_CENTERED, SDL_WINDOWPOS_CENTERED);
    SDL_ShowWindow(host->window);

    IMGUI_CHECKVERSION();
    ImGui::CreateContext();
    configureImGuiIo(ImGui::GetIO());
    ImGui::StyleColorsDark();
    ImGuiStyle& style = ImGui::GetStyle();
    style.ScaleAllSizes(scale);
    style.FontScaleDpi = scale;
    if (!gfxInit(host->window)) return SDL_APP_FAILURE;
    host->gfxReady = true;
    host->fonts = loadFonts();
    host->last = SDL_GetTicks();
    return SDL_APP_CONTINUE;
}

SDL_AppResult SDL_AppEvent(void* appstate, SDL_Event* event) {
    auto& host = *static_cast<Host*>(appstate);
    ImGui_ImplSDL3_ProcessEvent(event);
    handleEvent(host.app, host.window, *event);
    return host.app.quit ? SDL_APP_SUCCESS : SDL_APP_CONTINUE;
}

SDL_AppResult SDL_AppIterate(void* appstate) {
    auto& host = *static_cast<Host*>(appstate);
    const Uint64 now = SDL_GetTicks();
    step(host.app, static_cast<int>(std::min(now - host.last, kMaxFrameMs)));
    host.last = now;
    if (SDL_GetWindowFlags(host.window) & SDL_WINDOW_MINIMIZED) {
        SDL_Delay(10);
        return SDL_APP_CONTINUE;
    }
    gfxNewFrame();
    ImGui::NewFrame();
    drawFrame(host.app, host.fonts);
    ImGui::Render();
    gfxRender();
    return host.app.quit ? SDL_APP_SUCCESS : SDL_APP_CONTINUE;
}

void SDL_AppQuit(void* appstate, SDL_AppResult) {
    auto* host = static_cast<Host*>(appstate);
    if (host == nullptr) return;
    if (host->gfxReady) gfxShutdown();
    if (ImGui::GetCurrentContext() != nullptr) ImGui::DestroyContext();
    if (host->window != nullptr) SDL_DestroyWindow(host->window);
    delete host;  // SDL calls SDL_Quit() after this returns
}
```

```cpp
SDL_WindowFlags gfxPrepareWindow() {
    SDL_GL_SetAttribute(SDL_GL_CONTEXT_FLAGS, 0);
    SDL_GL_SetAttribute(SDL_GL_CONTEXT_PROFILE_MASK, SDL_GL_CONTEXT_PROFILE_ES);
    SDL_GL_SetAttribute(SDL_GL_CONTEXT_MAJOR_VERSION, 2);

bool gfxInit(SDL_Window* window) {
    target = window;
    context = SDL_GL_CreateContext(window);
    if (context == nullptr) {
        std::fprintf(stderr, "SDL_GL_CreateContext failed: %s\n", SDL_GetError());
        return false;
    }
    SDL_GL_MakeCurrent(window, context);
    SDL_GL_SetSwapInterval(1);
    ImGui_ImplSDL3_InitForOpenGL(window, context);
    ImGui_ImplOpenGL3_Init(nullptr);
    SDL_SetWindowSize(window, EM_ASM_INT({ return window.innerWidth; }), EM_ASM_INT({ return window.innerHeight; }));
    emscripten_set_resize_callback(EMSCRIPTEN_EVENT_TARGET_WINDOW, nullptr, EM_FALSE, onResize);
    return true;

    ImGui_ImplOpenGL3_NewFrame();
    ImGui_ImplSDL3_NewFrame();
}

    int width = 0;

    ImGui_ImplSDL3_Shutdown();
```

```go
func newTestServer(t *testing.T) *httptest.Server {
	t.Helper()
	hub := NewHub()
	codes := 0
	hub.newCode = func() string { codes++; return fmt.Sprintf("AAA%c", 'A'+codes-1) }
	seed := uint32(100)
	hub.newSeed = func() uint32 { seed++; return seed }
	srv := httptest.NewServer(hub)
	t.Cleanup(srv.Close)
	return srv
}

type client struct {
	t    *testing.T
	conn *websocket.Conn
}

func dial(t *testing.T, srv *httptest.Server) *client {
	t.Helper()
	ctx, cancel := context.WithTimeout(context.Background(), 5*time.Second)
	defer cancel()
	conn, _, err := websocket.Dial(ctx, "ws"+strings.TrimPrefix(srv.URL, "http"), nil)
	if err != nil {
		t.Fatalf("dial: %v", err)
	}
	t.Cleanup(func() { conn.CloseNow() })
	return &client{t: t, conn: conn}
}

func (c *client) send(text string) {
	c.t.Helper()
	ctx, cancel := context.WithTimeout(context.Background(), 5*time.Second)
	defer cancel()
	if err := c.conn.Write(ctx, websocket.MessageText, []byte(text)); err != nil {
		c.t.Fatalf("write %q: %v", text, err)
	}
}

func (c *client) expect(want string) {
	c.t.Helper()
	ctx, cancel := context.WithTimeout(context.Background(), 5*time.Second)
	defer cancel()
	_, data, err := c.conn.Read(ctx)
	if err != nil {
		c.t.Fatalf("waiting for %q: %v", want, err)
	}
	if got := string(data); got != want {
		c.t.Fatalf("got %q, want %q", got, want)
	}
}
```

```go
package main

import (
	"context"
	"fmt"
	"log"
	"math/rand/v2"
	"net/http"
	"strconv"
	"strings"
	"sync"
	"time"

	"github.com/coder/websocket"
)

const (
	maxMessageBytes = 4096
	writeTimeout    = 2 * time.Second
	codeLetters     = "ABCDEFGHJKLMNPQRSTUVWXYZ" // no I or O, which look like 1 and 0
	codeLength      = 4
	minStartLevel   = 1
	maxStartLevel   = 15
)

// Hub pairs browsers into two-player rooms and relays game messages between them.
// It reads only CREATE, JOIN and REMATCH; everything else goes to the opponent unchanged.
type Hub struct {
	mu      sync.Mutex
	rooms   map[string]*room
	newCode func() string
	newSeed func() uint32
}

type room struct {
	code    string
	level   int
	players [2]*player
	rematch [2]bool
}

type player struct {
	conn *websocket.Conn
	room *room // guarded by Hub.mu
}

// outgoing is a message to write after the hub lock is released.
type outgoing struct {
	to   *player
	text string
}

func NewHub() *Hub {
	return &Hub{rooms: map[string]*room{}, newCode: randomCode, newSeed: rand.Uint32}
}

func randomCode() string {
	b := make([]byte, codeLength)
	for i := range b {
		b[i] = codeLetters[rand.IntN(len(codeLetters))]
	}
	return string(b)
}

func (h *Hub) ServeHTTP(w http.ResponseWriter, r *http.Request) {
	conn, err := websocket.Accept(w, r, nil)
	if err != nil {
		log.Printf("websocket accept: %v", err)
		return
	}
	defer conn.CloseNow()
	conn.SetReadLimit(maxMessageBytes)
	p := &player{conn: conn}
	defer h.leave(p)
	for {
		typ, data, err := conn.Read(context.Background())
		if err != nil {
			return
		}
		if typ == websocket.MessageText {
			h.deliver(h.route(p, string(data)))
		}
	}
}

func (h *Hub) route(p *player, text string) []outgoing {
	h.mu.Lock()
	defer h.mu.Unlock()
	verb, arg, _ := strings.Cut(text, " ")
	if p.room == nil {
		switch verb {
		case "CREATE":
			return h.create(p, arg)
		case "JOIN":
			return h.join(p, arg)
		}
		return nil // relay traffic that raced a LEFT; nothing to do
	}
	switch verb {
	case "CREATE", "JOIN":
		return []outgoing{{p, "ERR already in a room"}}
	case "REMATCH":
		return h.rematch(p)
	}
	if other := p.room.opponent(p); other != nil {
		return []outgoing{{other, text}}
	}
	return nil
}

func (h *Hub) create(p *player, arg string) []outgoing {
	level, err := strconv.Atoi(arg)
	if err != nil || level < minStartLevel || level > maxStartLevel {
		return []outgoing{{p, "ERR bad start level"}}
	}
	code := h.newCode()
	for h.rooms[code] != nil {
		code = h.newCode()
	}
	r := &room{code: code, level: level}
	r.players[0] = p
	p.room = r
	h.rooms[code] = r
	return []outgoing{{p, "ROOM " + code}}
}

func (h *Hub) join(p *player, code string) []outgoing {
	r := h.rooms[code]
	if r == nil {
		return []outgoing{{p, "ERR unknown room"}}
	}
	if r.players[1] != nil {
		return []outgoing{{p, "ERR room is full"}}
	}
	r.players[1] = p
	p.room = r
	return r.start(h.newSeed())
}

func (h *Hub) rematch(p *player) []outgoing {
	r := p.room
	if r.opponent(p) == nil {
		return nil
	}
	r.rematch[r.seat(p)] = true
	if r.rematch[0] && r.rematch[1] {
		return r.start(h.newSeed())
	}
	return nil
}

func (h *Hub) leave(p *player) {
	h.mu.Lock()
	var out []outgoing
	if r := p.room; r != nil {
		delete(h.rooms, r.code)
		if other := r.opponent(p); other != nil {
			other.room = nil
			out = append(out, outgoing{other, "LEFT"})
		}
		p.room = nil
	}
	h.mu.Unlock()
	h.deliver(out)
}

// deliver writes outside the lock; a failed write closes that connection, whose read loop then cleans up.
func (h *Hub) deliver(out []outgoing) {
	for _, o := range out {
		ctx, cancel := context.WithTimeout(context.Background(), writeTimeout)
		_ = o.to.conn.Write(ctx, websocket.MessageText, []byte(o.text))
		cancel()
	}
}

func (r *room) start(seed uint32) []outgoing {
	r.rematch = [2]bool{}
	msg := fmt.Sprintf("START %d %d", seed, r.level)
	return []outgoing{{r.players[0], msg}, {r.players[1], msg}}
}

func (r *room) opponent(p *player) *player {
	if r.players[0] == p {
		return r.players[1]
	}
	return r.players[0]
}

func (r *room) seat(p *player) int {
	if r.players[0] == p {
		return 0
	}
	return 1
}
```

```cpp
#include <emscripten/emscripten.h>
#include <emscripten/websocket.h>

#include <cstring>
#include <utility>

#include "net/connection.hpp"

namespace tetris {
namespace {

// Browser WebSocket. Callbacks run on the main thread between frames (no pthreads).
class WebSocketConnection final : public Connection {
public:
    explicit WebSocketConnection(const std::string& url) {
        EmscriptenWebSocketCreateAttributes attrs;
        emscripten_websocket_init_create_attributes(&attrs);
        attrs.url = url.c_str();
        socket_ = emscripten_websocket_new(&attrs);
        if (socket_ <= 0) {
            closed_ = true;
            return;
        }
        emscripten_websocket_set_onopen_callback(socket_, this, onOpen);
        emscripten_websocket_set_onmessage_callback(socket_, this, onMessage);
        emscripten_websocket_set_onclose_callback(socket_, this, onClose);
        emscripten_websocket_set_onerror_callback(socket_, this, onError);
    }

    ~WebSocketConnection() override {
        if (socket_ <= 0) return;
        emscripten_websocket_close(socket_, 1000, "leaving");
        emscripten_websocket_delete(socket_);  // also drops the callbacks, so `this` is never used again
    }

    void send(const std::string& text) override {
        if (closed_) return;
        if (!open_) {
            outbox_.push_back(text);
            return;
        }
        emscripten_websocket_send_utf8_text(socket_, text.c_str());
    }

    std::vector<std::string> receive() override { return std::exchange(inbox_, {}); }
    bool closed() const override { return closed_; }

private:
    static EM_BOOL onOpen(int, const EmscriptenWebSocketOpenEvent*, void* self) {
        auto* connection = static_cast<WebSocketConnection*>(self);
        connection->open_ = true;
        for (const std::string& text : std::exchange(connection->outbox_, {})) connection->send(text);
        return EM_TRUE;
    }

    static EM_BOOL onMessage(int, const EmscriptenWebSocketMessageEvent* event, void* self) {
        if (!event->isText) return EM_TRUE;
        const auto* text = reinterpret_cast<const char*>(event->data);
        static_cast<WebSocketConnection*>(self)->inbox_.emplace_back(text, strnlen(text, event->numBytes));
        return EM_TRUE;
    }

    static EM_BOOL onClose(int, const EmscriptenWebSocketCloseEvent*, void* self) {
        static_cast<WebSocketConnection*>(self)->closed_ = true;
        return EM_TRUE;
    }

    static EM_BOOL onError(int, const EmscriptenWebSocketErrorEvent*, void* self) {
        static_cast<WebSocketConnection*>(self)->closed_ = true;
        return EM_TRUE;
    }

    EMSCRIPTEN_WEBSOCKET_T socket_ = 0;
    bool open_ = false;
    bool closed_ = false;
    std::vector<std::string> outbox_;
    std::vector<std::string> inbox_;
};

}  // namespace

bool duelsSupported() { return true; }

std::unique_ptr<Connection> connectToServer() {
    const std::string host = emscripten_run_script_string("location.host");
    return std::make_unique<WebSocketConnection>("ws://" + host + "/ws");
}

}  // namespace tetris
```

```cpp
constexpr float kDuelLeftColumns = 6.0f;    // hold panel and garbage meter, left of the local well
constexpr float kDuelRightColumns = 22.0f;  // local well, next/stats panel and the opponent's well
constexpr float kOpponentOffset = 16.0f;    // opponent well's left edge, in local cells from the local well

Layout computeDuelLayout() {
    const ImGuiViewport* vp = ImGui::GetMainViewport();
    const float columns = kDuelLeftColumns + kDuelRightColumns;
    const float cell =
        std::floor(std::min((vp->Size.y - 2 * kMargin) / kDrawnRows, (vp->Size.x - 2 * kMargin) / columns));
    return {cell, ImVec2(vp->Pos.x + (vp->Size.x - columns * cell) * 0.5f + kDuelLeftColumns * cell,
                         vp->Pos.y + (vp->Size.y - kDrawnRows * cell) * 0.5f)};
}

// Red bar left of a well showing garbage waiting to rise, one cell tall per line.
void drawGarbageMeter(ImDrawList* dl, float wellLeft, float wellBottom, float cell, int pending) {
    if (pending <= 0) return;
    const float height = static_cast<float>(std::min(pending, kVisibleHeight)) * cell;
    dl->AddRectFilled(ImVec2(wellLeft - 0.6f * cell, wellBottom - height), ImVec2(wellLeft - 0.25f * cell, wellBottom),
                      IM_COL32(230, 40, 40, 255));
}

void drawOpponent(ImDrawList* dl, const Layout& local, const Snapshot& snapshot, const Fonts& fonts) {
    const float cell = std::floor(local.cell * kOpponentScale);
    const float wellTop = cellTopLeft(local, 0, kVisibleHeight - 1).y;
    const float wellBottom = cellTopLeft(local, 0, 0).y + local.cell;
    const ImVec2 topLeft(local.origin.x + kOpponentOffset * local.cell, wellBottom - kVisibleHeight * cell);
    const ImVec2 bottomRight(topLeft.x + kBoardWidth * cell, wellBottom);
    dl->AddRectFilled(topLeft, bottomRight, IM_COL32(18, 18, 26, 255));
    dl->AddRect(ImVec2(topLeft.x - 2, topLeft.y - 2), ImVec2(bottomRight.x + 2, bottomRight.y + 2),
                IM_COL32(110, 110, 140, 255), 0.0f, 0, 2.0f);
    for (int y = 0; y < kVisibleHeight; ++y)
        for (int x = 0; x < kBoardWidth; ++x)
            if (const Cell c = snapshot.cells[y * kBoardWidth + x])
                drawCell(dl, ImVec2(topLeft.x + x * cell, wellBottom - (y + 1) * cell), cell, *c, 1.0f);
    drawGarbageMeter(dl, topLeft.x, wellBottom, cell, snapshot.pending);

    const float textSize = local.cell * 0.5f;
    char text[32];
    drawLabel(dl, fonts, textSize, ImVec2(topLeft.x, wellTop), "OPPONENT");
    std::snprintf(text, sizeof text, "SCORE %d", snapshot.score);
    drawLabel(dl, fonts, textSize, ImVec2(topLeft.x, wellTop + textSize * 1.8f), text);
    std::snprintf(text, sizeof text, "LINES %d", snapshot.lines);
    drawLabel(dl, fonts, textSize, ImVec2(topLeft.x, wellTop + textSize * 3.6f), text);
}
```
