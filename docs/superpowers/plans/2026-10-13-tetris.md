# Tetris (SDL3 + SDL_GPU + Dear ImGui) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a modern-guideline Tetris for macOS in C++20, where SDL3 owns the window/input, SDL_GPU (Metal) presents frames, and Dear ImGui draws everything.

**Architecture:** A pure, deterministic rules library (`tetris_core`: piece shapes, board, SRS kicks, 7-bag, `Game` state machine advanced in 1 ms ticks) with no SDL/ImGui dependency, unit-tested with doctest. An SDL-free input library (`tetris_input`: key → action mapping with DAS/ARR), also unit-tested. A thin executable (`tetris`) that wires SDL3 events, the fixed 1 ms step loop, and ImGui rendering (board drawn with `ImDrawList`, menus as ImGui windows).

**Tech Stack:** C++20, Apple clang 21, CMake ≥ 3.25 (4.4.4 installed) + Ninja, Homebrew SDL3 3.4.18, Dear ImGui v1.92.9b (FetchContent), doctest v2.4.12 (FetchContent), Press Start 2P font (SIL OFL).

**Spec:** `docs/superpowers/specs/2026-10-13-tetris-design.md`

## Global Constraints

- Language: C++20 (`CMAKE_CXX_STANDARD 20`, extensions off). Namespace for all project code: `tetris`.
- Dependency direction: `tetris` (app) → `tetris_input` → `tetris_core`. `src/core/` and `src/app/input.*` must never include SDL or ImGui headers.
- Board: 10 wide × 40 tall, **y = 0 is the bottom row, y grows upward**. Rows 0–19 visible, 20–39 hidden. Pieces spawn in rows y = 20–21 (the spec's "rows 21–22", 1-indexed).
- `Rotation` enumerators are `Zero, R, Two, L` (spec's `{0,R,2,L}`). The SRS function is named `rotateWithKicks` (spec's `tryRotate`) to avoid clashing with `Game`'s member.
- Timings: lock delay 500 ms, max 15 lock resets (counter resets on a new lowest row), line-clear flash 300 ms, soft drop 20× gravity, DAS 167 ms, ARR 33 ms, frame-time cap 100 ms, game advanced in 1 ms steps.
- Gravity: `(0.8 − (L−1)·0.007)^(L−1)` seconds per row, `L = min(level, 20)`.
- Scoring: 100/300/500/800 × level for 1/2/3/4 lines; soft drop 1/row; hard drop 2/row. Level = startLevel + lines / 10. Start level selectable 1–15.
- Warnings `-Wall -Wextra -Wpedantic` on our targets only. Debug: `-fsanitize=address,undefined` on everything. Release: `-O2 -DNDEBUG`.
- Window: resizable, high-pixel-density, minimum 640×720, vsync, fullscreen toggle ⌃⌘F and ⌥Enter, auto-pause on focus loss, keyboard only.
- Git: local repo only. Never add a remote or push.

```cpp
#include <SDL3/SDL.h>

#include <cstdio>

#include "imgui.h"
#include "imgui_impl_sdl3.h"
#include "imgui_impl_sdlgpu3.h"

namespace {

void renderFrame(SDL_GPUDevice* gpu, SDL_Window* window) {
    ImDrawData* drawData = ImGui::GetDrawData();
    const bool minimized = drawData->DisplaySize.x <= 0.0f || drawData->DisplaySize.y <= 0.0f;
    SDL_GPUCommandBuffer* commands = SDL_AcquireGPUCommandBuffer(gpu);
    SDL_GPUTexture* swapchain = nullptr;
    SDL_WaitAndAcquireGPUSwapchainTexture(commands, window, &swapchain, nullptr, nullptr);
    if (swapchain != nullptr && !minimized) {
        ImGui_ImplSDLGPU3_PrepareDrawData(drawData, commands);
        SDL_GPUColorTargetInfo target{};
        target.texture = swapchain;
        target.clear_color = SDL_FColor{0.06f, 0.06f, 0.09f, 1.0f};
        target.load_op = SDL_GPU_LOADOP_CLEAR;
        target.store_op = SDL_GPU_STOREOP_STORE;
        SDL_GPURenderPass* pass = SDL_BeginGPURenderPass(commands, &target, 1, nullptr);
        ImGui_ImplSDLGPU3_RenderDrawData(drawData, commands, pass);
        SDL_EndGPURenderPass(pass);
    }
    SDL_SubmitGPUCommandBuffer(commands);
}

}  // namespace

int main(int, char**) {
    if (!SDL_Init(SDL_INIT_VIDEO)) {
        std::fprintf(stderr, "SDL_Init failed: %s\n", SDL_GetError());
        return 1;
    }
    const float scale = SDL_GetDisplayContentScale(SDL_GetPrimaryDisplay());
    SDL_Window* window = SDL_CreateWindow("Tetris", static_cast<int>(800 * scale), static_cast<int>(900 * scale),
                                          SDL_WINDOW_RESIZABLE | SDL_WINDOW_HIGH_PIXEL_DENSITY | SDL_WINDOW_HIDDEN);
    if (window == nullptr) {
        std::fprintf(stderr, "SDL_CreateWindow failed: %s\n", SDL_GetError());
        return 1;
    }
    SDL_SetWindowMinimumSize(window, 640, 720);
    SDL_SetWindowPosition(window, SDL_WINDOWPOS_CENTERED, SDL_WINDOWPOS_CENTERED);
    SDL_ShowWindow(window);

    SDL_GPUDevice* gpu = SDL_CreateGPUDevice(
        SDL_GPU_SHADERFORMAT_MSL | SDL_GPU_SHADERFORMAT_METALLIB | SDL_GPU_SHADERFORMAT_SPIRV, false, nullptr);
    if (gpu == nullptr || !SDL_ClaimWindowForGPUDevice(gpu, window)) {
        std::fprintf(stderr, "SDL_GPU setup failed: %s\n", SDL_GetError());
        return 1;
    }
    SDL_SetGPUSwapchainParameters(gpu, window, SDL_GPU_SWAPCHAINCOMPOSITION_SDR, SDL_GPU_PRESENTMODE_VSYNC);

    IMGUI_CHECKVERSION();
    ImGui::CreateContext();
    ImGui::GetIO().IniFilename = nullptr;
    ImGui::StyleColorsDark();
    ImGuiStyle& style = ImGui::GetStyle();
    style.ScaleAllSizes(scale);
    style.FontScaleDpi = scale;
    ImGui_ImplSDL3_InitForSDLGPU(window);
    ImGui_ImplSDLGPU3_InitInfo info{};
    info.Device = gpu;
    info.ColorTargetFormat = SDL_GetGPUSwapchainTextureFormat(gpu, window);
    info.MSAASamples = SDL_GPU_SAMPLECOUNT_1;
    ImGui_ImplSDLGPU3_Init(&info);

    bool quit = false;
    while (!quit) {
        SDL_Event event;
        while (SDL_PollEvent(&event)) {
            ImGui_ImplSDL3_ProcessEvent(&event);
            if (event.type == SDL_EVENT_QUIT) quit = true;
        }
        if (SDL_GetWindowFlags(window) & SDL_WINDOW_MINIMIZED) {
            SDL_Delay(10);
            continue;
        }
        ImGui_ImplSDLGPU3_NewFrame();
        ImGui_ImplSDL3_NewFrame();
        ImGui::NewFrame();
        ImGui::ShowDemoWindow();
        ImGui::Render();
        renderFrame(gpu, window);
    }

    SDL_WaitForGPUIdle(gpu);
    ImGui_ImplSDL3_Shutdown();
    ImGui_ImplSDLGPU3_Shutdown();
    ImGui::DestroyContext();
    SDL_ReleaseWindowFromGPUDevice(gpu, window);
    SDL_DestroyGPUDevice(gpu);
    SDL_DestroyWindow(window);
    SDL_Quit();
    return 0;
}
```

```cpp
#pragma once

#include <array>
#include <cstdint>

namespace tetris {

enum class PieceType : std::uint8_t { I, O, T, S, Z, J, L };
inline constexpr int kPieceTypeCount = 7;

enum class Rotation : std::uint8_t { Zero, R, Two, L };

struct Point {
    int x = 0;
    int y = 0;
    friend bool operator==(const Point&, const Point&) = default;
};

struct Piece {
    PieceType type = PieceType::I;
    Rotation rotation = Rotation::Zero;
    Point pos;  // board position of the shape box's top-left corner (board y grows upward)

    std::array<Point, 4> cells() const;  // board coordinates
};

inline constexpr Point kSpawnPos{3, 21};

// Cells inside the piece's SRS bounding box; box y grows downward.
std::array<Point, 4> shapeCells(PieceType type, Rotation rotation);
Piece spawnPiece(PieceType type);
Rotation rotatedCW(Rotation rotation);
Rotation rotatedCCW(Rotation rotation);

}  // namespace tetris
```

```cpp
#include "core/piece.hpp"

namespace tetris {
namespace {

struct Shape {
    int boxSize;
    std::array<Point, 4> spawn;  // rotation Zero, box coordinates
};

// Guideline spawn orientations. Index matches PieceType.
constexpr std::array<Shape, kPieceTypeCount> kShapes{{
    {4, {{{0, 1}, {1, 1}, {2, 1}, {3, 1}}}},  // I
    {4, {{{1, 0}, {2, 0}, {1, 1}, {2, 1}}}},  // O
    {3, {{{1, 0}, {0, 1}, {1, 1}, {2, 1}}}},  // T
    {3, {{{1, 0}, {2, 0}, {0, 1}, {1, 1}}}},  // S
    {3, {{{0, 0}, {1, 0}, {1, 1}, {2, 1}}}},  // Z
    {3, {{{0, 0}, {0, 1}, {1, 1}, {2, 1}}}},  // J
    {3, {{{2, 0}, {0, 1}, {1, 1}, {2, 1}}}},  // L
}};

}  // namespace

std::array<Point, 4> shapeCells(PieceType type, Rotation rotation) {
    const Shape& shape = kShapes[static_cast<int>(type)];
    std::array<Point, 4> cells = shape.spawn;
    if (type == PieceType::O) return cells;
    // Each clockwise quarter turn inside an n×n box maps (x, y) to (n-1-y, x).
    for (int turn = 0; turn < static_cast<int>(rotation); ++turn)
        for (Point& c : cells) c = Point{shape.boxSize - 1 - c.y, c.x};
    return cells;
}

std::array<Point, 4> Piece::cells() const {
    std::array<Point, 4> result = shapeCells(type, rotation);
    for (Point& c : result) c = Point{pos.x + c.x, pos.y - c.y};
    return result;
}

Piece spawnPiece(PieceType type) { return Piece{type, Rotation::Zero, kSpawnPos}; }

Rotation rotatedCW(Rotation rotation) { return static_cast<Rotation>((static_cast<int>(rotation) + 1) % 4); }

Rotation rotatedCCW(Rotation rotation) { return static_cast<Rotation>((static_cast<int>(rotation) + 3) % 4); }

}  // namespace tetris
```

```cpp
#include "core/board.hpp"

#include <algorithm>
#include <cassert>

namespace tetris {

Cell Board::at(int x, int y) const {
    assert(inBounds(x, y));
    return cells_[index(x, y)];
}

void Board::set(int x, int y, Cell cell) {
    assert(inBounds(x, y));
    cells_[index(x, y)] = cell;
}

bool Board::collides(const Piece& piece) const {
    for (Point c : piece.cells())
        if (!inBounds(c.x, c.y) || cells_[index(c.x, c.y)]) return true;
    return false;
}

void Board::lock(const Piece& piece) {
    for (Point c : piece.cells()) set(c.x, c.y, piece.type);
}

std::vector<int> Board::fullRows() const {
    std::vector<int> rows;
    for (int y = 0; y < kBoardHeight; ++y) {
        bool full = true;
        for (int x = 0; x < kBoardWidth && full; ++x) full = cells_[index(x, y)].has_value();
        if (full) rows.push_back(y);
    }
    return rows;
}

void Board::removeRows(const std::vector<int>& rows) {
    int dst = 0;
    for (int src = 0; src < kBoardHeight; ++src) {
        if (std::find(rows.begin(), rows.end(), src) != rows.end()) continue;
        if (dst != src)
            for (int x = 0; x < kBoardWidth; ++x) cells_[index(x, dst)] = cells_[index(x, src)];
        ++dst;
    }
    for (; dst < kBoardHeight; ++dst)
        for (int x = 0; x < kBoardWidth; ++x) cells_[index(x, dst)] = std::nullopt;
}

}  // namespace tetris
```

```cpp
#include "core/srs.hpp"

#include <array>

namespace tetris {
namespace {

using Kicks = std::array<Point, 5>;
using KickTable = std::array<std::array<Kicks, 2>, 4>;  // [from rotation][0 = CW, 1 = CCW]

// Offsets use +y = up, as on the SRS reference tables.
constexpr KickTable kJlstzKicks{{
    {{{{{0, 0}, {-1, 0}, {-1, 1}, {0, -2}, {-1, -2}}}, {{{0, 0}, {1, 0}, {1, 1}, {0, -2}, {1, -2}}}}},    // from 0
    {{{{{0, 0}, {1, 0}, {1, -1}, {0, 2}, {1, 2}}}, {{{0, 0}, {1, 0}, {1, -1}, {0, 2}, {1, 2}}}}},          // from R
    {{{{{0, 0}, {1, 0}, {1, 1}, {0, -2}, {1, -2}}}, {{{0, 0}, {-1, 0}, {-1, 1}, {0, -2}, {-1, -2}}}}},    // from 2
    {{{{{0, 0}, {-1, 0}, {-1, -1}, {0, 2}, {-1, 2}}}, {{{0, 0}, {-1, 0}, {-1, -1}, {0, 2}, {-1, 2}}}}},  // from L
}};

constexpr KickTable kIKicks{{
    {{{{{0, 0}, {-2, 0}, {1, 0}, {-2, -1}, {1, 2}}}, {{{0, 0}, {-1, 0}, {2, 0}, {-1, 2}, {2, -1}}}}},  // from 0
    {{{{{0, 0}, {-1, 0}, {2, 0}, {-1, 2}, {2, -1}}}, {{{0, 0}, {2, 0}, {-1, 0}, {2, 1}, {-1, -2}}}}},  // from R
    {{{{{0, 0}, {2, 0}, {-1, 0}, {2, 1}, {-1, -2}}}, {{{0, 0}, {1, 0}, {-2, 0}, {1, -2}, {-2, 1}}}}},  // from 2
    {{{{{0, 0}, {1, 0}, {-2, 0}, {1, -2}, {-2, 1}}}, {{{0, 0}, {-2, 0}, {1, 0}, {-2, -1}, {1, 2}}}}},  // from L
}};

}  // namespace

std::optional<Piece> rotateWithKicks(const Board& board, const Piece& piece, RotateDir dir) {
    Piece rotated = piece;
    rotated.rotation = dir == RotateDir::CW ? rotatedCW(piece.rotation) : rotatedCCW(piece.rotation);
    if (piece.type == PieceType::O) {
        if (board.collides(rotated)) return std::nullopt;
        return rotated;
    }
    const KickTable& table = piece.type == PieceType::I ? kIKicks : kJlstzKicks;
    for (Point kick : table[static_cast<int>(piece.rotation)][dir == RotateDir::CW ? 0 : 1]) {
        Piece candidate = rotated;
        candidate.pos.x += kick.x;
        candidate.pos.y += kick.y;
        if (!board.collides(candidate)) return candidate;
    }
    return std::nullopt;
}

}  // namespace tetris
```

```cpp
namespace tetris {

Bag::Bag(std::uint32_t seed) : rng_(seed) { refill(); }

PieceType Bag::next() {
    const PieceType type = queue_.front();
    queue_.pop_front();
    if (static_cast<int>(queue_.size()) < kPieceTypeCount) refill();
    return type;
}

std::vector<PieceType> Bag::peek(int n) const {
    assert(n >= 0 && n <= kPieceTypeCount);
    return {queue_.begin(), queue_.begin() + n};
}

void Bag::refill() {
    std::array<PieceType, kPieceTypeCount> bag{PieceType::I, PieceType::O, PieceType::T, PieceType::S,
                                               PieceType::Z, PieceType::J, PieceType::L};
    std::shuffle(bag.begin(), bag.end(), rng_);
    queue_.insert(queue_.end(), bag.begin(), bag.end());
}
```

- **Steps:** `tick(ms)` runs `ms` one-millisecond steps.

- **During `Clearing`:** only `Pause` is accepted.
- **Pause:** `pause()` and `resume()` are idempotent, and resuming returns to whichever state was paused (`Playing` or `Clearing`).

```cpp
#include "core/game.hpp"

#include <algorithm>
#include <array>
#include <cassert>
#include <cmath>
#include <utility>

namespace tetris {

double gravityMsPerRow(int level) {
    const int l = std::min(level, kGravityLevelCap);
    return std::pow(0.8 - (l - 1) * 0.007, l - 1) * 1000.0;
}

int lineClearScore(int lines, int level) {
    static constexpr std::array<int, 5> kBase{0, 100, 300, 500, 800};
    assert(lines >= 0 && lines <= 4);
    return kBase[lines] * level;
}

int levelFor(int startLevel, int lines) { return startLevel + lines / kLinesPerLevel; }

Game::Game(std::uint32_t seed, int startLevel, Board board)
    : board_(std::move(board)), bag_(seed), startLevel_(startLevel), level_(startLevel) {
    assert(startLevel >= 1);
    spawn(bag_.next());
}

void Game::apply(Action action) {
    if (action == Action::Pause) {
        if (state_ == GameState::Paused)
            resume();
        else
            pause();
        return;
    }
    if (state_ != GameState::Playing) return;
    switch (action) {
    case Action::Left:
        if (tryMove(-1, 0)) onPlayerMoved();
        break;
    case Action::Right:
        if (tryMove(1, 0)) onPlayerMoved();
        break;
    case Action::RotateCW:
        rotate(RotateDir::CW);
        break;
    case Action::RotateCCW:
        rotate(RotateDir::CCW);
        break;
    case Action::HardDrop:
        hardDrop();
        break;
    case Action::Hold:
        holdPiece();
        break;
    case Action::Pause:
        break;
    }
}

void Game::tick(int ms) {
    for (int i = 0; i < ms; ++i) step();
}

void Game::pause() {
    if (state_ != GameState::Playing && state_ != GameState::Clearing) return;
    resumeState_ = state_;
    state_ = GameState::Paused;
}

void Game::resume() {
    if (state_ == GameState::Paused) state_ = resumeState_;
}

int Game::ghostDistance() const {
    Piece probe = active_;
    int distance = 0;
    for (;;) {
        --probe.pos.y;
        if (board_.collides(probe)) return distance;
        ++distance;
    }
}

void Game::step() {
    if (state_ == GameState::Clearing) {
        if (++clearTimerMs_ >= kClearDelayMs) finishClear();
        return;
    }
    if (state_ != GameState::Playing) return;
    if (onGround()) {
        dropTimerMs_ = 0.0;
        if (++lockTimerMs_ >= kLockDelayMs) lockPiece();
        return;
    }
    dropTimerMs_ += softDrop_ ? kSoftDropFactor : 1;
    const double msPerRow = gravityMsPerRow(level_);
    while (dropTimerMs_ >= msPerRow) {
        if (!tryMove(0, -1)) {
            dropTimerMs_ = 0.0;
            break;
        }
        dropTimerMs_ -= msPerRow;
        if (softDrop_) ++score_;
    }
}

void Game::spawn(PieceType type) {
    active_ = spawnPiece(type);
    lowestY_ = active_.pos.y;
    lockTimerMs_ = 0;
    lockResets_ = 0;
    dropTimerMs_ = 0.0;
    if (board_.collides(active_)) state_ = GameState::GameOver;  // block-out
}

bool Game::tryMove(int dx, int dy) {
    Piece moved = active_;
    moved.pos.x += dx;
    moved.pos.y += dy;
    if (board_.collides(moved)) return false;
    active_ = moved;
    updateLowest();
    return true;
}

void Game::rotate(RotateDir dir) {
    if (const auto rotated = rotateWithKicks(board_, active_, dir)) {
        active_ = *rotated;
        updateLowest();
        onPlayerMoved();
    }
}

void Game::updateLowest() {
    if (active_.pos.y < lowestY_) {
        lowestY_ = active_.pos.y;
        lockResets_ = 0;
        lockTimerMs_ = 0;
    }
}

void Game::onPlayerMoved() {
    if (lockTimerMs_ > 0 && lockResets_ < kMaxLockResets) {
        lockTimerMs_ = 0;
        ++lockResets_;
    }
}

bool Game::onGround() const {
    Piece below = active_;
    --below.pos.y;
    return board_.collides(below);
}

void Game::hardDrop() {
    const int distance = ghostDistance();
    active_.pos.y -= distance;
    score_ += 2 * distance;
    lockPiece();
}

void Game::holdPiece() {
    if (!canHold_) return;
    const PieceType current = active_.type;
    spawn(hold_ ? *hold_ : bag_.next());
    hold_ = current;
    canHold_ = false;
}

void Game::lockPiece() {
    board_.lock(active_);
    canHold_ = true;
    const auto cells = active_.cells();
    const bool lockOut =
        std::all_of(cells.begin(), cells.end(), [](Point c) { return c.y >= kVisibleHeight; });
    if (lockOut) {
        state_ = GameState::GameOver;
        return;
    }
    clearingRows_ = board_.fullRows();
    if (!clearingRows_.empty()) {
        state_ = GameState::Clearing;
        clearTimerMs_ = 0;
        return;
    }
    spawn(bag_.next());
}

void Game::finishClear() {
    const int cleared = static_cast<int>(clearingRows_.size());
    score_ += lineClearScore(cleared, level_);
    lines_ += cleared;
    level_ = levelFor(startLevel_, lines_);
    board_.removeRows(clearingRows_);
    clearingRows_.clear();
    state_ = GameState::Playing;
    spawn(bag_.next());
}

}  // namespace tetris
```

```cpp
#include "app/input.hpp"

namespace tetris {
namespace {

Action shiftAction(int dir) { return dir < 0 ? Action::Left : Action::Right; }

}  // namespace

void InputMapper::press(Key key, std::vector<Action>& out) {
    switch (key) {
    case Key::Left:
        leftHeld_ = true;
        startShift(-1, out);
        break;
    case Key::Right:
        rightHeld_ = true;
        startShift(1, out);
        break;
    case Key::SoftDrop:
        softDrop_ = true;
        break;
    case Key::HardDrop:
        out.push_back(Action::HardDrop);
        break;
    case Key::RotateCW:
        out.push_back(Action::RotateCW);
        break;
    case Key::RotateCCW:
        out.push_back(Action::RotateCCW);
        break;
    case Key::Hold:
        out.push_back(Action::Hold);
        break;
    case Key::Pause:
        out.push_back(Action::Pause);
        break;
    }
}

void InputMapper::release(Key key) {
    if (key == Key::SoftDrop) {
        softDrop_ = false;
        return;
    }
    if (key != Key::Left && key != Key::Right) return;
    const int releasedDir = key == Key::Left ? -1 : 1;
    (key == Key::Left ? leftHeld_ : rightHeld_) = false;
    if (dir_ != releasedDir) return;
    // Fall back to the other direction if it is still held; its DAS starts over.
    dir_ = leftHeld_ ? -1 : (rightHeld_ ? 1 : 0);
    dasMs_ = 0;
    arrMs_ = 0;
}

void InputMapper::tick(std::vector<Action>& out) {
    if (dir_ == 0) return;
    if (dasMs_ < kDasMs) {
        if (++dasMs_ == kDasMs) out.push_back(shiftAction(dir_));
        return;
    }
    if (++arrMs_ >= kArrMs) {
        arrMs_ = 0;
        out.push_back(shiftAction(dir_));
    }
}

void InputMapper::releaseAll() { *this = InputMapper{}; }

void InputMapper::startShift(int dir, std::vector<Action>& out) {
    dir_ = dir;
    dasMs_ = 0;
    arrMs_ = 0;
    out.push_back(shiftAction(dir));
}

}  // namespace tetris
```

```cpp
    case SDL_SCANCODE_DOWN:
        return Key::SoftDrop;
    case SDL_SCANCODE_SPACE:
        return Key::HardDrop;
    case SDL_SCANCODE_UP:
    case SDL_SCANCODE_X:
        return Key::RotateCW;
    case SDL_SCANCODE_Z:
    case SDL_SCANCODE_LCTRL:
    case SDL_SCANCODE_RCTRL:
        return Key::RotateCCW;
    case SDL_SCANCODE_C:
    case SDL_SCANCODE_LSHIFT:
    case SDL_SCANCODE_RSHIFT:
        return Key::Hold;
    case SDL_SCANCODE_ESCAPE:
    case SDL_SCANCODE_P:
        return Key::Pause;
    default:
        return std::nullopt;
    }
}

bool isFullscreenChord(const SDL_KeyboardEvent& key) {
    const bool ctrlCmdF =
        key.scancode == SDL_SCANCODE_F && (key.mod & SDL_KMOD_CTRL) != 0 && (key.mod & SDL_KMOD_GUI) != 0;
    const bool altEnter = key.scancode == SDL_SCANCODE_RETURN && (key.mod & SDL_KMOD_ALT) != 0;
    return ctrlCmdF || altEnter;
}
```

```cpp
#include "app/render.hpp"

#include <algorithm>
#include <array>
#include <cmath>
#include <cstdio>
#include <utility>
#include <vector>

#include "imgui.h"

namespace tetris {
namespace {

constexpr float kMargin = 16.0f;
constexpr int kDrawnRows = kVisibleHeight + 2;  // visible field plus the two spawn rows
constexpr float kLayoutColumns = 24.0f;         // 10 board columns + side panels
constexpr float kHiddenAlpha = 0.5f;

struct Rgb {
    int r, g, b;
};

// Guideline colors. Index matches PieceType.
constexpr std::array<Rgb, kPieceTypeCount> kPieceColors{{
    {0, 240, 240},  // I cyan
    {240, 240, 0},  // O yellow
    {160, 0, 240},  // T purple
    {0, 240, 0},    // S green
    {240, 0, 0},    // Z red
    {0, 0, 240},    // J blue
    {240, 160, 0},  // L orange
}};

ImU32 color(Rgb c, float alpha) { return IM_COL32(c.r, c.g, c.b, static_cast<int>(alpha * 255.0f)); }
Rgb lighten(Rgb c) { return {c.r + (255 - c.r) * 2 / 5, c.g + (255 - c.g) * 2 / 5, c.b + (255 - c.b) * 2 / 5}; }
Rgb darken(Rgb c) { return {c.r * 3 / 5, c.g * 3 / 5, c.b * 3 / 5}; }
Rgb pieceRgb(PieceType type) { return kPieceColors[static_cast<int>(type)]; }
float rowAlpha(int y) { return y >= kVisibleHeight ? kHiddenAlpha : 1.0f; }

struct Layout {
    float cell;     // cell size in points
    ImVec2 origin;  // top-left of the topmost drawn row (y = 21)
};

Layout computeLayout() {
    const ImGuiViewport* vp = ImGui::GetMainViewport();
    const float cell = std::floor(
        std::min((vp->Size.y - 2 * kMargin) / kDrawnRows, (vp->Size.x - 2 * kMargin) / kLayoutColumns));
    return {cell, ImVec2(vp->Pos.x + (vp->Size.x - kBoardWidth * cell) * 0.5f,
                         vp->Pos.y + (vp->Size.y - kDrawnRows * cell) * 0.5f)};
}

ImVec2 cellTopLeft(const Layout& l, int x, int y) {
    return ImVec2(l.origin.x + x * l.cell, l.origin.y + (kDrawnRows - 1 - y) * l.cell);
}

void drawCell(ImDrawList* dl, ImVec2 p, float size, PieceType type, float alpha) {
    const Rgb base = pieceRgb(type);
    const float bevel = std::max(1.0f, std::floor(size * 0.12f));
    const ImVec2 q(p.x + size, p.y + size);
    dl->AddRectFilled(p, q, color(base, alpha));
    dl->AddRectFilled(p, ImVec2(q.x, p.y + bevel), color(lighten(base), alpha));  // top
    dl->AddRectFilled(p, ImVec2(p.x + bevel, q.y), color(lighten(base), alpha));  // left
    dl->AddRectFilled(ImVec2(p.x, q.y - bevel), q, color(darken(base), alpha));   // bottom
    dl->AddRectFilled(ImVec2(q.x - bevel, p.y), q, color(darken(base), alpha));   // right
}

void drawWell(ImDrawList* dl, const Layout& l) {
    const ImVec2 top = cellTopLeft(l, 0, kVisibleHeight - 1);
    const ImVec2 bottom(top.x + kBoardWidth * l.cell, top.y + kVisibleHeight * l.cell);
    dl->AddRectFilled(top, bottom, IM_COL32(18, 18, 26, 255));
    dl->AddRect(ImVec2(top.x - 2, top.y - 2), ImVec2(bottom.x + 2, bottom.y + 2), IM_COL32(110, 110, 140, 255),
                0.0f, 0, 2.0f);
}

void drawBoardCells(ImDrawList* dl, const Layout& l, const Game& game) {
    for (int y = 0; y < kDrawnRows; ++y)
        for (int x = 0; x < kBoardWidth; ++x)
            if (const Cell c = game.board().at(x, y)) drawCell(dl, cellTopLeft(l, x, y), l.cell, *c, rowAlpha(y));
    for (int y : game.clearingRows()) {
        if (y >= kDrawnRows) continue;
        const ImVec2 p = cellTopLeft(l, 0, y);
        dl->AddRectFilled(p, ImVec2(p.x + kBoardWidth * l.cell, p.y + l.cell), IM_COL32(255, 255, 255, 220));
    }
}

void drawActivePiece(ImDrawList* dl, const Layout& l, const Game& game) {
    Piece ghost = game.active();
    ghost.pos.y -= game.ghostDistance();
    const Rgb rgb = pieceRgb(ghost.type);
    for (Point c : ghost.cells()) {
        if (c.y >= kDrawnRows) continue;
        const ImVec2 p = cellTopLeft(l, c.x, c.y);
        dl->AddRect(ImVec2(p.x + 1, p.y + 1), ImVec2(p.x + l.cell - 1, p.y + l.cell - 1), color(rgb, 0.6f), 0.0f, 0,
                    2.0f);
    }
    for (Point c : game.active().cells())
        if (c.y < kDrawnRows) drawCell(dl, cellTopLeft(l, c.x, c.y), l.cell, game.active().type, rowAlpha(c.y));
}

void drawMiniPiece(ImDrawList* dl, ImVec2 topLeft, float cell, PieceType type, float alpha) {
    for (Point c : shapeCells(type, Rotation::Zero))
        drawCell(dl, ImVec2(topLeft.x + c.x * cell, topLeft.y + c.y * cell), cell, type, alpha);
}

void drawLabel(ImDrawList* dl, const Fonts& fonts, float size, ImVec2 pos, const char* text) {
    dl->AddText(fonts.hud, size, pos, IM_COL32(230, 230, 240, 255), text);
}

void drawSidePanels(ImDrawList* dl, const Layout& l, const Game& game, const Fonts& fonts) {
    const float textSize = l.cell * 0.6f;
    const float mini = l.cell * 0.7f;
    const float top = cellTopLeft(l, 0, kVisibleHeight - 1).y;

    const float holdX = l.origin.x - 5.5f * l.cell;
    drawLabel(dl, fonts, textSize, ImVec2(holdX, top), "HOLD");
    if (const auto held = game.hold())
        drawMiniPiece(dl, ImVec2(holdX, top + l.cell), mini, *held, game.canHold() ? 1.0f : 0.35f);

    const float rightX = l.origin.x + (kBoardWidth + 1) * l.cell;
    drawLabel(dl, fonts, textSize, ImVec2(rightX, top), "NEXT");
    const std::vector<PieceType> next = game.next(5);
    for (int i = 0; i < static_cast<int>(next.size()); ++i)
        drawMiniPiece(dl, ImVec2(rightX, top + l.cell + i * 2.5f * mini), mini, next[i], 1.0f);

    float y = top + l.cell + 5 * 2.5f * mini + l.cell;
    const std::array<std::pair<const char*, int>, 3> stats{
        {{"SCORE", game.score()}, {"LEVEL", game.level()}, {"LINES", game.lines()}}};
    char value[32];
    for (const auto& [label, number] : stats) {
        drawLabel(dl, fonts, textSize, ImVec2(rightX, y), label);
        std::snprintf(value, sizeof value, "%d", number);
        drawLabel(dl, fonts, textSize, ImVec2(rightX, y + textSize * 1.4f), value);
        y += textSize * 3.5f;
    }
}

void beginMenu(const char* id) {
    const ImGuiViewport* vp = ImGui::GetMainViewport();
    ImGui::SetNextWindowPos(vp->GetCenter(), ImGuiCond_Always, ImVec2(0.5f, 0.5f));

                 ImGuiWindowFlags_NoDecoration | ImGuiWindowFlags_AlwaysAutoResize | ImGuiWindowFlags_NoMove |
                     ImGuiWindowFlags_NoSavedSettings);
}

    ImGui::PushFont(fonts.hud, ImGui::GetFontSize() * 2.0f);
    ImGui::TextUnformatted(title);
    ImGui::PopFont();
    ImGui::Spacing();
}

bool menuButton(const char* label) { return ImGui::Button(label, ImVec2(ImGui::GetFontSize() * 12.0f, 0.0f)); }

}  // namespace

void drawGame(const Game& game, const Fonts& fonts) {
    const ImGuiViewport* vp = ImGui::GetMainViewport();
    ImGui::SetNextWindowPos(vp->Pos);
    ImGui::SetNextWindowSize(vp->Size);
    ImGui::Begin("##game", nullptr,
                 ImGuiWindowFlags_NoDecoration | ImGuiWindowFlags_NoMove | ImGuiWindowFlags_NoSavedSettings |
                     ImGuiWindowFlags_NoBackground | ImGuiWindowFlags_NoBringToFrontOnFocus |
                     ImGuiWindowFlags_NoInputs);
    ImDrawList* dl = ImGui::GetWindowDrawList();

    drawWell(dl, layout);
    if (game.state() != GameState::Paused) {
        drawBoardCells(dl, layout, game);

        beginMenu("##gameover");

        if (menuButton("Restart")) command = UiCommand::Restart;
        if (menuButton("Quit to menu")) command = UiCommand::QuitToMenu;
        ImGui::End();
    }
    return command;
}
```

```cpp
#include <SDL3/SDL.h>

#include <algorithm>
#include <cstdint>
#include <cstdio>
#include <optional>
#include <vector>

#include "app/fonts.hpp"
#include "app/input.hpp"
#include "app/keymap.hpp"
#include "app/render.hpp"
#include "core/game.hpp"
#include "imgui.h"
#include "imgui_impl_sdl3.h"
#include "imgui_impl_sdlgpu3.h"

using namespace tetris;

namespace {

constexpr Uint64 kMaxFrameMs = 100;  // longer stalls are dropped, not replayed

struct App {
    Screen screen = Screen::Start;
    int startLevel = 1;
    std::optional<Game> game;
    InputMapper input;
    std::vector<Action> pending;
    bool quit = false;

    void newGame() {
        game.emplace(static_cast<std::uint32_t>(SDL_GetTicksNS()), startLevel);
        input.releaseAll();
        pending.clear();
        screen = Screen::Playing;
    }
};

void applyCommand(App& app, UiCommand command) {
    switch (command) {
    case UiCommand::None:
        break;
    case UiCommand::Play:
    case UiCommand::Restart:
        app.newGame();
        break;
    case UiCommand::Resume:
        if (app.game) app.game->resume();
        break;
    case UiCommand::QuitToMenu:
        app.game.reset();
        app.screen = Screen::Start;
        break;
    case UiCommand::QuitApp:
        app.quit = true;
        break;
    }
}

void handleKey(App& app, SDL_Window* window, const SDL_KeyboardEvent& key) {
    if (key.down && isFullscreenChord(key)) {
        const bool fullscreen = (SDL_GetWindowFlags(window) & SDL_WINDOW_FULLSCREEN) != 0;
        SDL_SetWindowFullscreen(window, !fullscreen);
        return;
    }
    if (key.repeat || app.screen != Screen::Playing) return;  // DAS/ARR replaces OS key repeat
    const std::optional<Key> mapped = keyForScancode(key.scancode);
    if (!mapped) return;
    if (key.down)
        app.input.press(*mapped, app.pending);
    else
        app.input.release(*mapped);
}

// Advances input auto-repeat and the game in 1 ms steps.
void step(App& app, int ms) {
    if (!app.game) return;
    Game& game = *app.game;
    auto flush = [&] {
        for (Action action : app.pending) game.apply(action);
        app.pending.clear();
    };
    flush();
    for (int i = 0; i < ms; ++i) {
        app.input.tick(app.pending);
        flush();
        game.setSoftDrop(app.input.softDrop());
        game.tick(1);
    }
}

void renderFrame(SDL_GPUDevice* gpu, SDL_Window* window) {
    ImDrawData* drawData = ImGui::GetDrawData();
    const bool minimized = drawData->DisplaySize.x <= 0.0f || drawData->DisplaySize.y <= 0.0f;
    SDL_GPUCommandBuffer* commands = SDL_AcquireGPUCommandBuffer(gpu);
    SDL_GPUTexture* swapchain = nullptr;
    SDL_WaitAndAcquireGPUSwapchainTexture(commands, window, &swapchain, nullptr, nullptr);
    if (swapchain != nullptr && !minimized) {
        ImGui_ImplSDLGPU3_PrepareDrawData(drawData, commands);
        SDL_GPUColorTargetInfo target{};
        target.texture = swapchain;
        target.clear_color = SDL_FColor{0.06f, 0.06f, 0.09f, 1.0f};
        target.load_op = SDL_GPU_LOADOP_CLEAR;
        target.store_op = SDL_GPU_STOREOP_STORE;
        SDL_GPURenderPass* pass = SDL_BeginGPURenderPass(commands, &target, 1, nullptr);
        ImGui_ImplSDLGPU3_RenderDrawData(drawData, commands, pass);
        SDL_EndGPURenderPass(pass);
    }
    SDL_SubmitGPUCommandBuffer(commands);
}

}  // namespace

int main(int, char**) {
    if (!SDL_Init(SDL_INIT_VIDEO)) {
        std::fprintf(stderr, "SDL_Init failed: %s\n", SDL_GetError());
        return 1;
    }
    const float scale = SDL_GetDisplayContentScale(SDL_GetPrimaryDisplay());
    SDL_Window* window = SDL_CreateWindow("Tetris", static_cast<int>(800 * scale), static_cast<int>(900 * scale),
                                          SDL_WINDOW_RESIZABLE | SDL_WINDOW_HIGH_PIXEL_DENSITY | SDL_WINDOW_HIDDEN);
    if (window == nullptr) {
        std::fprintf(stderr, "SDL_CreateWindow failed: %s\n", SDL_GetError());
        return 1;
    }
    SDL_SetWindowMinimumSize(window, 640, 720);
    SDL_SetWindowPosition(window, SDL_WINDOWPOS_CENTERED, SDL_WINDOWPOS_CENTERED);
    SDL_ShowWindow(window);

    SDL_GPUDevice* gpu = SDL_CreateGPUDevice(
        SDL_GPU_SHADERFORMAT_MSL | SDL_GPU_SHADERFORMAT_METALLIB | SDL_GPU_SHADERFORMAT_SPIRV, false, nullptr);
    if (gpu == nullptr || !SDL_ClaimWindowForGPUDevice(gpu, window)) {
        std::fprintf(stderr, "SDL_GPU setup failed: %s\n", SDL_GetError());
        return 1;
    }
    SDL_SetGPUSwapchainParameters(gpu, window, SDL_GPU_SWAPCHAINCOMPOSITION_SDR, SDL_GPU_PRESENTMODE_VSYNC);

    IMGUI_CHECKVERSION();
    ImGui::CreateContext();
    ImGui::GetIO().IniFilename = nullptr;
    ImGui::StyleColorsDark();
    ImGuiStyle& style = ImGui::GetStyle();
    style.ScaleAllSizes(scale);
    style.FontScaleDpi = scale;
    ImGui_ImplSDL3_InitForSDLGPU(window);
    ImGui_ImplSDLGPU3_InitInfo info{};
    info.Device = gpu;
    info.ColorTargetFormat = SDL_GetGPUSwapchainTextureFormat(gpu, window);
    info.MSAASamples = SDL_GPU_SAMPLECOUNT_1;
    ImGui_ImplSDLGPU3_Init(&info);
    const Fonts fonts = loadFonts();

    App app;
    Uint64 last = SDL_GetTicks();
    while (!app.quit) {
        SDL_Event event;
        while (SDL_PollEvent(&event)) {
            ImGui_ImplSDL3_ProcessEvent(&event);
            switch (event.type) {
            case SDL_EVENT_QUIT:
                app.quit = true;
                break;
            case SDL_EVENT_WINDOW_FOCUS_LOST:
                if (app.game) app.game->pause();
                app.input.releaseAll();  // key-up events are lost while unfocused
                break;
            case SDL_EVENT_KEY_DOWN:
            case SDL_EVENT_KEY_UP:
                handleKey(app, window, event.key);
                break;
            default:
                break;
            }
        }

        const Uint64 now = SDL_GetTicks();
        step(app, static_cast<int>(std::min(now - last, kMaxFrameMs)));
        last = now;

        if (SDL_GetWindowFlags(window) & SDL_WINDOW_MINIMIZED) {
            SDL_Delay(10);
            continue;
        }

        ImGui_ImplSDLGPU3_NewFrame();
        ImGui_ImplSDL3_NewFrame();
        ImGui::NewFrame();
        UiCommand command = UiCommand::None;
        if (app.screen == Screen::Start) {
            command = drawStartScreen(fonts, app.startLevel);
        } else {
            drawGame(*app.game, fonts);
            command = drawOverlay(*app.game, fonts);
        }
        ImGui::Render();
        renderFrame(gpu, window);
        applyCommand(app, command);
    }

    SDL_WaitForGPUIdle(gpu);
    ImGui_ImplSDL3_Shutdown();
    ImGui_ImplSDLGPU3_Shutdown();
    ImGui::DestroyContext();
    SDL_ReleaseWindowFromGPUDevice(gpu, window);
    SDL_DestroyGPUDevice(gpu);
    SDL_DestroyWindow(window);
    SDL_Quit();
    return 0;
}
```

## Notes for the implementer

- **Ctrl overlap:** Ctrl is both rotate-counterclockwise and part of ⌃⌘F, so pressing ⌃⌘F during play also rotates once. This is accepted for v1.
- **Global macOS shortcuts:** macOS may take some shortcuts before SDL sees them (for example ⌃← for Mission Control). The default game keys don't need modifiers.
- **Sanitizer findings:** if ASan reports a problem inside SDL or Metal system frameworks rather than our code, write down the stack and ask before suppressing it. Don't silence reports that point at `src/`.
